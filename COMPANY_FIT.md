# EMU-OPS — Company and Team Fit

These are potential engineering/employer matches, not claims of use, endorsement or partnership.

## Project thesis

A CHIP-8 emulator: a small virtual computer that loads a game program and runs its instructions on a simple screen and keypad.

## Qualcomm

**Relevant public technical areas:** Embedded software, processor systems and emulation.

**Potential roles:** Systems Engineer, Embedded Software Engineer, Developer Tools Engineer, Firmware Engineer or Software Engineer.

**Evidence to develop:** Rust-based experimental emulator with CPU registers, stack, timers, memory, CHIP-8 font, 64×32 display buffer and a minifb desktop window. ROMs must be supplied by the user; a missing ROM should produce an explicit error instead of generating fake content. Emulator correctness depends on opcode semantics and timing behavior.
